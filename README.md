Booking app

Next.js 16
TypeScript
Better Auth med GitHub OAuth
PostgreSQL med Prisma
Tailwind CSS
shadcn ui

## vad som behövs

- Node.js 18+ och npm
- PostgreSQL databas
- GitHub OAuth credentials

## Installation

1. **Clone the repository**

   git clone <min repo>

2. **Installera dependencies**

   npm install

## Använd Locally

npm run dev

## Användning

1. **Sign in** Logga in med github
2. **Browse availability** Du kan se vilka rum som är lediga
3. **Book a room** Du kan boka med att väla ett rum och ledigt datum
